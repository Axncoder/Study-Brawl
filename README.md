# Study Brawl

Study Brawl is a fast-paced trivia battle game where you face off against a bot and try to outsmart it with correct answers. Earn XP, coins, and power-ups while climbing levels and collecting avatars. Play quick rounds, shop for upgrades, and see if you can land a spot on the leaderboard.

**Play it here:** https://axncoder.github.io/Study-Brawl/

## Why I made it

Revising can be hard to focus on, and flashcards often feel dull. I wanted to put students in a more exciting situation, where wrong answers cost you health and every question feels like a fight. The aim is to make studying more engaging and keep students focused.

## How it works

- Pick a category and difficulty, then battle a bot
- Answer correctly to damage the bot; answer wrong and you take damage
- Earn XP, coins and power-ups (50/50 and Heal)
- Spend coins in the avatar shop

## Built with

HTML, CSS and JavaScript. I built the first version in Python, then rebuilt it as a browser game, using AI assistance as a coding tool.
